# Guías de autoestudio · Matemáticas

Guías didácticas-lúdicas para el aprendizaje de las matemáticas con estudiantes de
bachillerato en zonas rurales de Colombia. Programa PTIES.

Cada guía son ocho unidades de una hora, con ejercicios que se corrigen solos y
mesas de trabajo manipulables. Funcionan en el navegador, sin instalar nada y sin
cuenta de usuario. El avance de cada estudiante se guarda en su propio navegador.

## Contenido

| Carpeta | Guía | Estado |
|---|---|---|
| `combinatoria/` | Combinatoria y probabilidad | publicada · 8 unidades, 102 ejercicios |
| `areas/` | Perímetros, áreas y productos notables | publicada · 8 unidades, 104 ejercicios |
| `logica/` | Lógica y acertijos | 4 de 8 unidades publicadas |
| `volumenes/` | Volúmenes, áreas superficiales y perspectivas | publicada · 8 unidades, 103 ejercicios |

## Cómo se ve

La portada está en `index.html`, en la raíz. Cada guía tiene su propio `index.html`
con las ocho unidades, y de ahí se entra a `u1.html` … `u8.html`.
